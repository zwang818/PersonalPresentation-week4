# ZWANG 前端作品集 · 设计规范

更新时间：2026-10-09。本文以项目当前的 `style.css` 和 `index.html` 为依据，记录已实现的设计规则。尺寸除特别说明外均为 CSS px；行高为无单位倍数。未显式设置行高的文字使用浏览器的 `normal`，未显式设置字重的普通文字继承默认值 `400`。

## 1. 设计风格与配色

风格关键词：字体海报、暖白纸感、深墨绿、荧光绿、石材质感、圆角陈列卡片。通过超大紧凑标题与小字号信息形成对比，以留白、背景色块和细边框划分结构。

| 角色 | CSS 变量 | 色值 | 用途 |
| --- | --- | --- | --- |

| 强调色 / 主交互色 | `--accent` | `#C2FF32` | 胶囊按钮、跳到作品链接、文字选中背景 |

## 2. 字体与文字层级

### 字体栈

```css
/* 海报大标题、品牌和石材字母 */
--display: Impact, "Arial Black", "Helvetica Neue", sans-serif;

/* 正文、中文、按钮与辅助信息 */
--body: Arial, "PingFang SC", "Microsoft YaHei", sans-serif;
```

使用系统字体，不依赖在线字体下载。展示字体优先用于英文大写；中文使用正文栈中的可用字体。字体缺失时由后备字体接替，字形与视觉宽度可能变化。

## 3. 间距、留白与布局

所有元素使用 `box-sizing: border-box`；默认 `margin`、`padding` 清零，再按组件明确设置。当前设计以 `6–10px` 的细节间距、`14–20px` 的组件间距、`25–45px` 的模块留白为主，不强制所有数值落在同一倍数网格。

### 布局尺寸

- 页面外框最大宽度 `1800px`，水平居中。
- 主标题最大宽度 `1150px`；石材展示区最大宽度 `1230px`，均水平居中。
- 桌面作品区采用三列等宽网格：`repeat(3, minmax(0, 1fr))`。
- 桌面截图展示区高度为 `clamp(210px, 22vw, 340px)`；图片保持原始比例并居中，不裁切。
- 卡片使用纵向 Flex 布局，底部操作区通过 `margin-top: auto` 对齐。

## 4. 组件样式与交互规则

### 按钮

- 形状：`border-radius: 999px`，完整胶囊轮廓。
- 默认背景：`#C2FF32`；文字与箭头：`#192916`。
- 作品按钮最小高度 `36px`；导航按钮最小高度 `33px`。实际高度还受文字和内边距影响。
- 无边框、无阴影；文字与箭头水平排列并居中，不换行。
- 导航按钮悬停变为 `#AEDF27`；作品卡片悬停时，卡片内按钮变为 `#B2ED25`。
- 背景与变换过渡 `0.2s`。当前按钮没有单独的点击动画或禁用态定义。
- 作品按钮是整张卡片链接中的视觉操作提示；页面跳转使用原生 `<a>`，不嵌套额外链接。

### 作品卡片

- 默认背景：`#EAEAE0`；圆角 `14px`，手机端 `12px`。
- 默认边框：`1px solid transparent`，预留边框空间；悬停时边框颜色为 `#C3C9B8`，避免尺寸跳动。
- 悬停背景：`#E3E5D8`；背景与边框过渡 `0.25s`。
- 不使用投影，也不整体抬升卡片；通过色块、边框与截图变化反馈操作。
- 截图圆角 `5px`，默认 `grayscale(1)` 并使用 `mix-blend-mode: multiply` 与卡片底色融合。
- 卡片悬停或键盘聚焦时，截图恢复 `grayscale(0)`，并向上移动 `4px`；过渡 `0.35s`。
- 截图使用等比缩放、`object-fit: contain`，宽高不超过展示区。注册截图最大高度 `94%`，问答截图最大宽度 `94%`，食谱截图最大宽度 `98%`。
- 整卡可点击，使用 `target="_blank"` 和 `rel="noopener noreferrer"` 打开项目。

### 导航栏

- 顶部居中，宽度随内容自适应；当前不使用固定定位或吸顶。
- 容器背景：`#E1E3D5`；圆角 `15px`；无边框、无阴影。
- 内部结构为「😎 ZWANG 品牌 + 荧光绿探索作品按钮」。
- 品牌跳转首屏，按钮跳转作品区；使用页面内锚点与平滑滚动。

### 页面边框与分隔线

| 元素 | 圆角 | 边框 / 分隔线 | 阴影 |
| --- | --- | --- | --- |
| 页面外框 | 桌面 `22px`；手机 `16px` | `2px solid #DCD8CF` | 无 |
| 作品卡片 | 桌面 `14px`；手机 `12px` | 默认 `1px solid transparent`；悬停 `#C3C9B8` | 无 |
| 导航容器 | `15px` | 无 | 无 |
| 胶囊按钮 | `999px` | 无 | 无 |
| 项目截图 | `5px` | 无 | 不添加额外阴影；图片自身内容保留 |
| 石材区底部 / 页脚顶部 | 无 | `1px solid #DCD8CF` | 无 |

石材字母的深色侧面来自 SVG 中偏移叠放的文字，属于装饰图形，不作为通用组件阴影。

### 焦点与动效

- 所有链接的键盘焦点使用 `3px solid #192916` 外轮廓，偏移 `5px`，确保可辨识。
- “跳到作品”辅助链接仅在获得焦点时显示，背景使用强调绿，圆角 `30px`，内边距 `12px 20px`。
- 非文本装饰图形不进入辅助技术阅读顺序；项目截图提供替代文字。
- 遵循 `prefers-reduced-motion: reduce`：关闭平滑滚动与 CSS 过渡。

## 5. 延续设计时的原则

1. 保持「暖白底 + 墨绿文字 + 少量荧光绿」的主视觉关系。
2. 大标题保持紧凑，小字号说明保持轻量；普通正文内容继续采用中文友好的字体栈。
3. 新作品沿用现有卡片结构：顶部标签、等比截图、标题与说明、底部分类与操作提示。
4. 新组件优先通过背景色和细边框建立层级，延续无投影规则。
5. 新增设计值优先复用本文的颜色、圆角和间距；实际代码更新后同步更新本文，避免文档与实现偏离。
